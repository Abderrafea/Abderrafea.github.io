# Abderrafea Elamri — Portfolio

Portfolio bilingue français / anglais : AI Engineering, Data Science et développement logiciel.

## Fichiers

- `index.html` : version française
- `en.html` : English version
- `style.css` : responsive layout and light/dark themes
- `app.js` : theme switch and project details
- `assets/` : portrait, CV and favicon

## Aperçu local

Run `python -m http.server 4173` from this directory, then open http://localhost:4173.

## Publication

In repository Settings > Pages, select Deploy from a branch, then main and / (root).

The original downloadable CV is in French. Project illustrations use fictional sample data.
